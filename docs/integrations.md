# Integrations

## Available integrations
Taskly integrates with Slack, GitHub and Google Calendar. Integrations are available on the Pro and Business plans.

## Connecting Slack
Open Settings > Integrations > Slack and select "Connect". Choose the Slack workspace and the channel for notifications. You must be a Slack workspace admin to approve the connection.

## Connecting GitHub
Open Settings > Integrations > GitHub, sign in to GitHub and select the repositories to link. Mention a task ID such as TSK-123 in a pull request to link it to that task.

## Google Calendar
Open Settings > Integrations > Google Calendar and sign in with Google. Tasks with due dates then appear in your calendar.
