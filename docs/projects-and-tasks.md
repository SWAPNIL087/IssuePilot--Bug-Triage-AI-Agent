# Projects and Tasks

## Creating a project
Select "New project" in the sidebar, enter a name and choose a template. You can invite team members while creating it.

## Creating and assigning tasks
Select "Add task" inside a project, enter a title and choose an assignee and a due date. A task can have one assignee.

## Recurring tasks
Open a task, select the due date and choose "Repeat". You can repeat a task daily, weekly, monthly or on custom days. Recurring tasks are available on the Pro and Business plans.

## Archiving a project
Open the project menu and select "Archive". Archived projects are read-only and can be restored at any time from Settings > Workspace > Archived.
